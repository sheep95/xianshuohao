# 阶段 2.5：视觉与文案重构

2026-11-18，按用户确认的三条样稿完成规则文案与现有首页重构。本次目标达成，暂停等待下一阶段指令。

## 文案

15 个摩擦原型、45 个行为水位、每个水位两种标题，共 90 个标题全部重写；45 个执行接口全部改写。标题使用直接、略有戏剧感的日常表达，正文继续承担可观察动作与阈值。

三条已确认正文分别为夜间不外放、借用前收到同意、调温前发出目标温度，已经落入 JSON。其余 42 条现有正文保留，避免文案调整改变执行边界。分类名称、原型与水位标识、默认选择、空间与有效期保持原样。真实摩擦字段仍为内部分析，不出现在卡片上。

示例标题：

- 23:00 后，不附赠全寝直播。
- 放在桌上，不代表加入共享套餐。
- 调个温度，不必执行秘密任务。
- 散场时间，不是开始收拾的时间。
- 垃圾到桶口，就别挑战叠叠乐。

四列表与九套静态示例均已同步。生成脚本和后端业务逻辑没有修改。

## 视觉与交互

卡片改为米白圆角纸张、轻阴影和一小段胶带；朱红仅保留在品牌与试行草案印章上。条目之间使用留白替代硬线，标题改为本地黑体字体栈，正文增加行距。空间选择使用柔和的浅绿色选中底色。

换批按钮使用骰子图形，悬停时有轻微转动，减少动态效果模式中关闭转动。原有循环九套示例逻辑不变，不请求模型。

每条规则增加淡色“无人认领”标签，明确为预告文字，不是按钮；页面说明暂不可点击。未生成真实认领或通过状态。

本次以完整文案和手机阅读舒适度为优先：1280×1100 与 1440×1100 下默认卡完整显示；800 像素高桌面窗口及手机需要滚动。没有截断正文或缩小字体来强行塞入一屏。后续正式导出卡仍属原阶段 5。

## 运行与验收

在项目根目录运行：

```powershell
npm.cmd --prefix frontend run dev
```

打开 http://127.0.0.1:3000 。如果已有预览占用端口，先停止它再运行。首页无需后端。

1. 查看默认五条新文案，每条都有具体动作、执行接口与“无人认领”标签。
2. 点击“换一批，掷一组”，查看下一套；切换三个空间，确认规则与元数据一起变化。
3. 点击“四人宿舍示例”恢复初始卡；刷新可保留选中的示例。
4. 在窄屏阅读，检查正文完整、无水平溢出，认领标签不遮挡标题。

验证命令：

```powershell
.\backend\.venv\Scripts\python.exe scripts/sync_examples.py --check
.\backend\.venv\Scripts\python.exe -m pytest backend/tests -q
npm.cmd --prefix frontend run lint
npm.cmd --prefix frontend run typecheck
npm.cmd --prefix frontend run build
npm.cmd --prefix frontend run test:e2e
```
