# 真实摩擦四列表

这份表完整对应 `backend/app/data/rule_library.json`：15 个真实摩擦原型、45 个具体行为水位，以及 90 个预置幽默表达。每个水位展示第一个预置表达；另一个表达保留在 JSON 中供静态切换使用。

条文组合方式为：`幽默表达 + 空格 + 固定行为句`。幽默不会代替行为条件；执行接口把下一步缩成可以直接做的小动作，不以解释或道歉证明合规。以下内容全部为静态预置，不代表已接入或调用大模型。

水位是可选的具体做法，不保证由严到松排序。一次最多选择 5 个不同摩擦点，每个摩擦点只选一个水位；不足 5 条时使用对应空间的补充建议，并在生成前向参与者展示。

第一版“一学期”固定按 120 天计算，界面仍显示“一学期”。这只是空间约定的有效期限，不包含长期监督、评分或违规记录。具体部署日期由后续房间功能计算。

## 三个空间的默认建议

- **宿舍 / 合租 · 一周**：拿到一张关于声音、灯光和共享空间的入住小宪法。
  - 深夜声音：23:00 后不外放（`night_sound/quiet_2300`）。
  - 灯光：23:00 后关闭顶灯，使用台灯（`lights/desk_lamp_2300`）。
  - 物品借用：借他人物品前收到“可以”（`borrowing/ask_before_borrowing`）。
  - 垃圾：吃完后 30 分钟内封袋丢餐盒（`trash/meal_boxes_30m`）。
  - 空调温度：改温度前在群里发新温度（`air_conditioning/announce_temperature`）。
- **短租 / 民宿 · 三天**：拿到一张关于浴室、厨房和离场整理的同行小宪法。
  - 浴室使用：单次连续占用浴室不超过 15 分钟（`bathroom/bathroom_15m`）。
  - 食物存放：公共区域食物标“自用”或“共享”（`food/label_food_use`）。
  - 使用后清洁：用完桌面后 5 分钟内擦掉残渣水渍（`cleaning/wipe_table_5m`）。
  - 深夜声音：23:00 后不外放（`night_sound/quiet_2300`）。
  - 离场检查：最后离开时关门并发“已离开”（`departure/close_door_and_report`）。
- **社团活动室 · 一学期**：拿到一张关于设备、桌面和活动复位的开门小宪法。
  - 使用时段：使用前登记开始和结束时间（`time_slots/register_slot`）。
  - 共享设备：投影用完关机，遥控器放设备旁（`shared_devices/projector_off`）。
  - 公共桌面：结束使用后 5 分钟内清空个人物品（`shared_desks/clear_desk_5m`）。
  - 活动复位：活动结束后 10 分钟内归还共享材料（`reset_room/return_materials_10m`）。
  - 离场检查：最后离开时关闭照明和空调（`departure/lights_and_ac_off`）。
